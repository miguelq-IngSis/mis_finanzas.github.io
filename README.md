# FinanFlow · Mis Finanzas

Aplicación web progresiva (PWA) para administrar ingresos, gastos, pagos pendientes, proyecciones y respaldos personales. Los datos quedan guardados únicamente en el almacenamiento local del dispositivo.

## Usar e instalar en el celular

1. Publica esta carpeta en un sitio con HTTPS (por ejemplo, GitHub Pages, Netlify o Vercel).
2. Abre la dirección publicada desde Chrome o Edge en Android.
3. Pulsa **Instalar** cuando aparezca el botón, o usa el menú del navegador y elige **Instalar aplicación** / **Agregar a pantalla de inicio**.

La primera visita necesita conexión para descargar la app. Después, la interfaz y la información guardada funcionan sin conexión. Antes de cambiar de celular o borrar los datos del navegador, usa **Datos → Exportar Copia de Seguridad (JSON)**.

## Funciones

- Ingreso principal y entradas adicionales por mes.
- Registro de gastos, categorías, métodos de pago y notas.
- Estados pendiente/pagado, filtros y búsqueda.
- Saldo disponible y gráficos por categoría.
- Simulación de compras y pagos en cuotas.
- Exportación CSV e importación/exportación de respaldo JSON.
